# Worked examples

Concrete展開例 index. Each file shows [`../process.ja.md`](../process.ja.md) and [`../output-structure.ja.md`](../output-structure.ja.md) applied to one scenario, and closes with the general principles it illustrates. None of these is a standard form — see the quality-checklist's warning against over-transferring from any single example.

- [`education-lesson.ja.md`](education-lesson.ja.md) — a 4th-grade social-studies lesson (「地域学習・教育」パターン). The original example, from `dwg7/chukei` issue #3.
- [`education-train-the-trainer.ja.md`](education-train-the-trainer.ja.md) — a teacher training session on the same pattern, but where the deliverable is a reusable *skill* rather than a finished lesson. Introduces the 最終利用者 vs 展開する立場 distinction.
- [`disaster-preparedness-briefing.ja.md`](disaster-preparedness-briefing.ja.md) — a short municipal disaster-preparedness briefing (「防災の共通認識」パターン). Introduces an "想定される質問への対応" addition for high-stakes partners.
- [`multi-stakeholder-advocacy.ja.md`](multi-stakeholder-advocacy.ja.md) — a talk to an audience of several distinct stakeholder types at once (「対外的な説明・アピール」パターン). Introduces handling a non-single audience.
- [`data-gap-discovery.ja.md`](data-gap-discovery.ja.md) — a dataset whose *name* matches the question exactly while its content does not answer it (「データ不足の把握」パターン). From `dwg7/kataribe`'s real dossier work, verified against source data by `dwg7/kitavolca`. Introduces the distinction between an absence you can find by searching and an absence disguised as a match.
